## 如何补齐 2016 年文章
提供文章来源后，用 `wechat_to_obsidian.py` 一键入库：

1. 把文章链接（mp.weixin.qq.com 直链，或 weixin.sogou.com 跳转链）每行一个写入：
   `D:\WorkBuddy\WorkSpace\scripts\urls.txt`
2. 运行：
   ```
   python D:\WorkBuddy\WorkSpace\scripts\wechat_to_obsidian.py urls.txt --only-year 2016
   ```
3. 脚本会自动抓取、抽取标题/作者/发布时间/正文，转为带 YAML frontmatter 的 Markdown，
   并归档到本目录下的 `2016/` 子目录。

### 获取链接的两种可行方式
- **方式 A（最省事）**：在手机/网页微信中打开该公众号 → 进入「历史消息」→ 找到 2016 年文章 → 逐篇「复制链接」粘贴到 urls.txt。
- **方式 B（批量）**：使用第三方「微信公众号文章导出」工具（如 wechat-article-exporter，需你用自己的公众号后台扫码登录）批量导出该号全部文章，再把 2016 年的链接/HTML 交给我入库。
